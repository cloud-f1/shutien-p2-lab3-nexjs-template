# E158 — [GENERALIZABLE] Feedback Loop Closure

> Phase 40 — Self-Review Improvements | Size: S (2 SP) | Deps: none
> Source: self-review 2026-04-24 — tag is written but no one reads it until manual promote

## Problem

`@debugger` tags lessons with `[GENERALIZABLE]` in `docs/context/debug-log.md` when a fix applies beyond this project. The intent is that `@memory-curator` consumes them and promotes to Tier 0 (`~/.claude/template-memory/`) via `/athena:promote`.

Current state of this loop:

- **Producer**: `@debugger` tags consistently (5+ references in `.claude/agents/debugger.md`)
- **Consumer**: only `/athena:promote` — runs when human remembers to invoke it
- **Backpressure**: none — tags accumulate unbounded in `debug-log.md`
- **Visibility**: no surface in `session-summary.md` or SessionStart telling the user "you have N pending lessons"

Net effect: the feedback loop is open. High-value lessons sit in `debug-log.md` for weeks.

## Solution

Replace passive nudge with **active auto-trigger via PostToolUse hook**. When `@debugger` writes to `debug-log.md` and the file contains ≥3 `[GENERALIZABLE]` tags newer than the last-promote watermark, the hook auto-spawns `@memory-curator` in dry-run mode. The dry-run output is appended to the next `session-summary.md` and the user decides whether to commit the promotion.

Three mechanisms:

1. **PostToolUse hook `auto-promote-check.sh`** — fires when Edit/Write touches `docs/context/debug-log.md`, `qa-patterns.md`, or `review-findings.md`. Counts pending tags. If ≥3 → launches `@memory-curator --dry-run` as background subagent; output goes to `docs/context/promotion-proposals/<ts>.md`.
2. **Watermark file** — `docs/context/.last-promote-ts` (epoch). Hook uses `git log --since="@$ts"` to count new tags.
3. **Auto-commit of proposal, not of promotion** — the hook never writes to `~/.claude/template-memory/`. It only *drafts* proposals. Human (or `/athena:promote --apply <file>`) approves.

## Implementation

### PostToolUse hook — `auto-promote-check.sh`

```bash
#!/usr/bin/env bash
# Fires when @debugger or humans edit context log files.
# Auto-spawns @memory-curator in dry-run mode when tag threshold crossed.
set -euo pipefail

# Hook input: $CLAUDE_FILE_PATH set by PostToolUse contract
target="${CLAUDE_FILE_PATH:-}"
case "$target" in
  */docs/context/debug-log.md|*/docs/context/qa-patterns.md|*/docs/context/review-findings.md) ;;
  *) exit 0 ;;  # not our target
esac

watermark_file="docs/context/.last-promote-ts"
since=0
[[ -f "$watermark_file" ]] && since=$(cat "$watermark_file")

# Count [GENERALIZABLE] entries added since watermark
count=$(git log --since="@$since" --pretty=tformat: --patch -- \
  docs/context/debug-log.md \
  docs/context/qa-patterns.md \
  docs/context/review-findings.md \
  2>/dev/null \
  | grep -cE '^\+.*\[GENERALIZABLE\]' || true)

(( count >= 3 )) || exit 0

# Threshold crossed — spawn dry-run proposal
ts=$(date +%Y%m%d-%H%M%S)
proposal="docs/context/promotion-proposals/${ts}.md"
mkdir -p "$(dirname "$proposal")"

# Emit a structured request that the main agent will pick up in session-summary
cat > "$proposal" <<EOF
# Promotion Proposal — ${ts}

Auto-generated by \`scripts/hooks/auto-promote-check.sh\` after threshold of ${count} pending [GENERALIZABLE] lessons.

## Next step
\`/athena:promote --apply ${proposal}\`

## Pending lessons
EOF

# Append the raw tagged lines for context
for f in docs/context/debug-log.md docs/context/qa-patterns.md docs/context/review-findings.md; do
  [[ -f "$f" ]] || continue
  grep -Hn '\[GENERALIZABLE\]' "$f" >> "$proposal" 2>/dev/null || true
done

# Telemetry (non-blocking)
printf '{"ts":"%s","event":"auto_promote_proposed","count":%d,"file":"%s"}\n' \
  "$(date -u +%FT%TZ)" "$count" "$proposal" >> .claude/audit.jsonl
```

### settings.json registration

```json
"hooks": {
  "PostToolUse": [
    {
      "matcher": "Edit|Write",
      "hooks": [
        {
          "type": "command",
          "command": "bash scripts/hooks/auto-promote-check.sh"
        }
      ]
    }
  ]
}
```

### promote.md --dry-run

```markdown
## Flags

- `--dry-run` — List pending `[GENERALIZABLE]` entries (file:line + first 80 chars) without writing to `~/.claude/template-memory/` or updating watermark. Read-only.

## Watermark

On real run (non-dry), after successful promotion:
  date +%s > docs/context/.last-promote-ts
  git add docs/context/.last-promote-ts
```

## Alignment / Cross-Epic Hooks

- **Writes to**: `docs/context/promotion-proposals/<ts>.md`, `docs/context/.last-promote-ts`, `.claude/audit.jsonl` event `auto_promote_proposed`
- **Shared format with**: E160 (auto-compact also writes to `promotion-proposals/` using the same schema)
- **Reads from**: `.claude/audit.jsonl` (watermark comparison), git log on `docs/context/*.md`
- **Downstream of**: all `[GENERALIZABLE]`-producing agents (@debugger primarily, @reviewer in future)
- **Consumed by**: `/athena:promote --apply <file>` (human-approved promotion to Tier 0)
- **Does NOT bump** Stop-verifier rule count (this is a hook, not a rule)

## Acceptance Criteria

- [ ] PostToolUse hook fires when Edit/Write touches `debug-log.md`, `qa-patterns.md`, or `review-findings.md`
- [ ] Hook writes proposal file only when count ≥ 3 since watermark
- [ ] Hook stays silent when count < 3 (no noise)
- [ ] `/athena:promote --dry-run` lists pending entries, does not touch Tier 0 or watermark
- [ ] `/athena:promote --apply <file>` consumes a proposal, updates `docs/context/.last-promote-ts` to current epoch on success
- [ ] `@memory-curator` only processes entries added after the watermark
- [ ] First-time run (watermark=0) processes all historical tags
- [ ] Proposal format matches E160's output format (shared schema)

## Out of Scope

- Auto-running `/athena:promote` without human gate — promotion quality still needs review
- Tagging from agents other than `@debugger` (future: `@reviewer` could tag patterns)
