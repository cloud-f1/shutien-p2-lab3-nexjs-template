## High (8)

1. **Seed script ships public admin credentials with no production guard** (`next-app/drizzle/seed.ts`) — `pnpm db:seed` unconditionally inserts `admin@example.com` / `Admin123!` (emailVerified, role=admin) against any `DATABASE_URL`, and those passwords are published in the repo → full account takeover. *Fix: refuse to run when `NODE_ENV==='production'` (and/or require `ALLOW_SEED=1`); never seed static admin passwords — generate/require one via env.*

2. **Stale JWT role lets a demoted user keep write/admin access until re-login** (`next-app/lib/auth.ts:55-72`) — `jwt()` writes `token.role` only at sign-in; `setUserRole()` updates the DB but never the active token, so a demoted editor still passes `requireEditor()` and a demoted admin still reaches `/dashboard/admin`. *Fix: have `requireAdmin()`/`requireEditor()` re-read `role` from the DB (`getUserById`) instead of trusting `session.user.role`.*

3. **Dark-mode primary color fails WCAG contrast (~2.2:1) as chart stroke/link text** (`next-app/app/globals.css`) — dark `--primary` (#193cb8) on dark bg is 2.23:1 (card ~2.0:1), below the 3:1 non-text / 4.5:1 text thresholds; chart lines are nearly invisible. *Fix: raise dark-mode `--primary` lightness (toward `oklch(0.623 0.214 259.815)`) or add a brighter dark chart token.*

4. **Settings forms: inputs lack `aria-invalid` and errors not programmatically linked** (`next-app/app/(dashboard)/dashboard/settings/_password-form.tsx`, `_profile-form.tsx`) — validity conveyed by red text only (WCAG 1.4.1 / 3.3.1 / 4.1.3); SR users hear nothing on invalid submit. *Fix: mirror the login form — add `aria-invalid`, give each error `<p>` an `id` + `role="alert"`, wire `aria-describedby` on the Input.*

5. **"Forgot password?" is a non-functional `href="#"` anchor** (`next-app/app/(auth)/login/_login-form.tsx:102-107`) — focusable and announced as a link but does nothing (WCAG 2.4.4 / 4.1.2). *Fix: point it at the real reset route, or render as a `<button>`/disabled span; never ship `href="#"`.*

6. **zod item-title validation messages left in English** (`next-app/lib/validations/items.ts:4,8`) — `"Title is required"` / `"Title is too long"` while all other validation files are zh-Hant. *Fix: translate to zh-Hant (e.g. `請輸入標題` / `標題過長`). Note: this file is currently unused dead code — true impact is low; fold into the deadcode cleanup below.*

7. **Server action returns English `"Title is required"`** (`next-app/actions/items.ts:18,42`) — lone untranslated server-action error string. *Fix: return `{ error: "請輸入標題" }`.* (Currently unreachable from the UI; see dead-links finding.)

8. **DeleteButton confirm dialog and labels in English** (`next-app/components/delete-button.tsx:20,25`) — `confirm("Delete this item?")` and `Delete`/`Deleting…` vs the fully-translated admin delete button. *Fix: translate to zh-Hant. Note: this component is dead code (see #18) — deleting it resolves the i18n gap too.*

## Medium (10)

9. **Auth Server Actions are unauthenticated and unthrottled** (`next-app/actions/auth.ts`) — no rate limiting on `loginAction` (bcrypt brute-force), `registerUser` leaks account existence (enumeration), `resendVerificationEmail` accepts any email and sends with no cooldown (email-bombing). *Fix: add IP/identifier rate limiting + per-email cooldown; make registration non-enumerating.*

10. **Profile/name/image never refresh after edit (stale JWT)** (`next-app/lib/auth.ts`) — `updateProfile()` writes the DB but the JWT-cookie name/image are snapshotted at sign-in, so the sidebar/settings show old values; `revalidatePath` can't fix it. *Fix: call Auth.js `update()`/`unstable_update` on success, handle `trigger==='update'` in `jwt()`, or read name/image from the DB in the layout.*

11. **Item create/edit/list routes are linked everywhere but don't exist (404s)** (`next-app/components/data-table.tsx:159,219,223,390` + page.tsx:62, nav-main.tsx:39, app-sidebar.tsx:39) — no `app/(dashboard)/dashboard/items` directory, so the advertised CRUD flow is dead. *Fix: build the missing routes (guarding each with `requireEditor()`), or remove the dead links.*

12. **Submit/server status banners are silent to screen readers** (`_password-form.tsx`, `_profile-form.tsx`, `_resend-button.tsx`, `_login-form.tsx`, `_register-form.tsx`) — dynamic success/error `<p>`s have no `role`/`aria-live` (WCAG 4.1.3). *Fix: wrap in `role="status"`/`role="alert"` or add `aria-live`.*

13. **FieldError (`role=alert`) not tied to its input via `aria-describedby`/`aria-errormessage`** (`next-app/components/ui/field.tsx:176-225`) — re-focusing an errored field announces label + invalid state but not the message (WCAG 1.3.1 / 3.3.1). *Fix: give FieldError a stable `id` and wire `aria-describedby` on the Input when invalid.*

14. **Role selector combobox has no accessible name** (`next-app/app/(dashboard)/dashboard/admin/_role-selector.tsx:34-49`) — SR announces only the current value, not that it sets a role nor for which user (WCAG 4.1.2 / 1.3.1). *Fix: add `aria-label={`變更 ${userEmail} 的角色`}`.*

15. **Chart series are indistinguishable and chart has no text alternative** (`next-app/components/chart-area-interactive.tsx`) — both series use `var(--primary)` (WCAG 1.4.1) and the SVG exposes no summary (WCAG 1.1.1). *Fix: give the two series distinct colors and add `role="img"` + summarizing `aria-label` (or a hidden data table).*

16. **`'Live'` badge text untranslated** (`next-app/components/section-cards.tsx:40,66,95`) — English `Live` among zh-Hant card text. *Fix: translate to `即時`.*

17. **English fallback `'there'` in dashboard greeting** (`next-app/app/(dashboard)/dashboard/page.tsx:54`) — `歡迎回來，there` for nameless users. *Fix: `session.user.name ?? "您"`.*

18. **Orphaned items feature cluster** (`next-app/components/delete-button.tsx`, `next-app/actions/items.ts`, `next-app/lib/validations/items.ts`) — `DeleteButton` has zero importers; `createItem`/`updateItem` are never reached from any UI; the validations file is fully unreferenced. *Fix: delete the three files (keep `itemsTable`, which is still read), or finish wiring the items routes.*

19. **English fallback display name `'User'` in sidebar** (`next-app/app/(dashboard)/layout.tsx:27`) — rendered as the visible account name in NavUser. *Fix: `name ?? "使用者"`.*

## Low (12)

20. **`updateProfile` stores an arbitrary user-controlled image URL rendered as `<img src>`** (`next-app/actions/user.ts`) — `z.string().url()` accepts any scheme/host; impact is client-side (tracking pixel / referer leak) and currently self-only. *Fix: restrict to `https` + an allowlist in `updateProfileSchema`.*

21. **`deleteItem`/`updateItem` silently no-op on cross-user IDs with no return value** (`next-app/actions/items.ts:27-35`) — ownership-scoped `WHERE` matching zero rows is indistinguishable from success. *Fix: return `{success}`/`{error}` on `rowCount===0`, or branch on `isAdmin` if admins should manage all items.*

22. **Sidebar keyboard toggle lacks on-screen affordance/announcement** (`next-app/components/ui/sidebar.tsx`) — Cmd/Ctrl+B has no hint and `SidebarTrigger` exposes no `aria-expanded`. *Fix: add `aria-expanded={open}` (+ `aria-controls`) and `aria-keyshortcuts="Meta+B Control+B"`.*

23. **`'John Doe'` English example placeholder on register form** (`next-app/app/(auth)/register/_register-form.tsx:68`). *Fix: optionally use `王小明`.*

24. **Chart date axis/tooltip use `en-US` locale (English months)** (`next-app/components/chart-area-interactive.tsx:250,261`). *Fix: use `zh-Hant` in both formatters.*

25. **Resend-verification button/messages in English** (`next-app/app/(auth)/verify-email/_resend-button.tsx:14,26`) — also the success-color logic keys off `message.includes("sent")`. *Fix: translate strings (`驗證信已寄出！`, `寄送中…`, `重新寄送驗證信`) and switch color logic to a success flag.*

26. **`requireEditor()` becomes dead once the items cluster is removed** (`next-app/lib/permissions.ts:22-28`). *Fix: remove the export when deleting `actions/items.ts` (keep `requireAuth`/`requireAdmin`/`isAdmin`/`canEdit`).*

27. **DataTable drag-reorder is local-only and silently discarded** (`next-app/components/data-table.tsx`) — no `order` column; revalidation/navigation drops manual ordering. *Fix: remove the drag handle, or add a `sortOrder` column + persist via a reorder action.*

28. **Dashboard/DataTable link to nonexistent `/dashboard/items/*` routes; no `not-found.tsx`** (`next-app/components/data-table.tsx`) — same dead routes as #11, plus there are no error/not-found boundaries. *Fix: add the routes or remove the links; add `app/not-found.tsx` (+ consider `error.tsx`).*

29. **recharts shipped eagerly with no lazy/Suspense boundary** (`next-app/components/chart-area-interactive.tsx`) — heavy lib in initial dashboard JS for a below-the-fold static-data chart. *Fix: `next/dynamic` import wrapped in `<Suspense>`.*

30. **Unused shadcn primitive `components/ui/breadcrumb.tsx`** — no importers. *Fix: delete (re-add via shadcn if needed).*

31. **Unused shadcn primitive `components/ui/drawer.tsx` (+ `vaul` dependency)** — sole importer of `vaul`. *Fix: delete the file and remove `vaul` from `package.json`.*

32. **Unused export `getUserById` in `lib/queries.ts:13`** — no importers. *Fix: remove the export.*

33. **Unused drizzle inferred types `NewUser`, `Item`, `NewItem` in `lib/schema.ts:72-74`** — idiomatic boilerplate, never imported. *Fix: optionally remove (keep tables, `User`, `Role`, auth tables).*
