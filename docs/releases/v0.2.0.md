# v0.2.0

**AI App Template** — a production-ready **Next.js 16** SaaS starter, AI-Ready and modular. v0.2.0 builds on the v0.1.0 foundation (Next.js migration + modular `@saas` registry + billing) with a full **design-system pass**, real **backend-backed SaaS surfaces**, and **deployment enablement**.

> **Demo:** `docker compose up --build` → http://localhost:3000 (mailpit on :8025)
> Logins: `admin@example.com / Admin123!` · `editor@example.com / Editor123!` · `viewer@example.com / Viewer123!`
> **Docs:** https://ai-coding-nexjs-template-docs.pages.dev/

## ✨ New in v0.2.0

- **Cobalt design system** — oklch tokens + a premium FX layer (aurora / shimmer / glow / reveal, `prefers-reduced-motion` safe), redesigned landing page, polished dashboard, **⌘K command palette**, notifications dropdown, breadcrumbs, expanded tabbed settings, auth split-screen, and a `/dashboard/components` reference page. Locked in by a Playwright **visual-regression (VRT)** gate.
- **Backend SaaS surfaces** (migration 0005, owner/admin RBAC):
  - **API keys** — sha256-hashed, shown once, with a bearer-auth verify helper.
  - **Webhooks** — HMAC-SHA256 signed dispatch + retry/backoff + a delivery log.
  - **Audit log** — sensitive actions recorded; admin-only viewer.
  - **Team invitations** + permission matrix — invite / accept / revoke via `/invite/[token]`.
  - **Billing UI** — plan summary, usage meter, invoice history.
  - **Notifications** — real, per-user, mark-read.
- **Deployment enablement** — one-service **Zeabur** (`zbpack.json`) **and** **GCP Cloud Run + Cloud SQL** runbooks, `.env.example`, a `deploy-config` skill, and a one-shot tool installer.
- **DX** — fresh-DB **migration test** (`pnpm db:test-migrate`) wired into `make smoke`; an **enriched demo seed** that populates every surface; coverage scoped to the db-free logic layer (**80.7%** statements).
- **Fix** — API-key prefix is now delimiter-free (hex), so a base64url secret containing `_`/`-` can't be mis-parsed (previously valid keys could be rejected intermittently).

## Stack

**Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Drizzle ORM / Postgres · Auth.js v5 (JWT sessions)**

## Foundation (from v0.1.0)

- **Auth.js v5** — Credentials (bcrypt) + Google OAuth, JWT sessions, email verification, password reset, rate-limiting; **3-tier RBAC** (`admin` / `editor` / `viewer`) re-read from the DB.
- **AI-Ready modular `@saas` registry** — `registry.json` → `public/r/*.json` distributes whole feature modules; each ships a machine-readable `module.manifest.json` (+ JSON Schema, `pnpm module:validate`); MCP wiring lets an AI agent install a module by natural language.
- **Modular billing** — a `PaymentProvider` abstraction (default Stripe) with **`@saas/billing-stripe`** (Checkout + signed idempotent webhook) and **`@saas/billing-ecpay`** (綠界 定期定額 recurring).
- Full **繁體中文** UI · Dockerized local stack · VitePress dev-docs on Cloudflare Pages · the **Athena** AI agent team.

## Quality

- **232 unit tests** green · **80.7%** statement coverage on the db-free logic layer.
- Playwright **e2e** + **VRT**, `make smoke`, and a fresh-DB **migration test** that proves migrations apply from scratch.
