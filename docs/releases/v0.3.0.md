# v0.3.0

**AI App Template** — a production-ready **Next.js 16** SaaS starter, AI-Ready and modular. v0.3.0 takes the v0.2.0 backend surfaces from "demo-grade" to **production- and fork-ready**: a hardened billing money-path, a generated-from-Zod API contract, a real public REST API, security headers, password-reset + invite emails, a Stripe billing portal, CI, observability — and a full sweep that makes the template (and its Athena AI-dev tooling) Next.js-native end to end.

## ✨ New in v0.3.0 (the E274–E293 program, Phases 63–68)

### Production hardening
- **Billing money-path** (E274) — plan-id → UUID FK fix, persisted `currentPeriodEnd`, a cancel-subscription UI, a real `reconcile()`, an ECPay renewal cron, and a SQLSTATE-23505 idempotent webhook upsert. A real payment can now be initiated, sustained, and recovered.
- **Public REST API** (E291) — `app/api/v1/items` authenticated by the E267 **API keys** (`verifyApiKey` + scopes); the keys panel now issues keys that authenticate a real surface.
- **Generated OpenAPI contract** (E281) — `@asteasolutions/zod-to-openapi` derives `docs/openapi.yaml` from the Zod validation layer, served live at `/api/openapi`, with a **coverage guard** + a **smoke drift-gate** so the contract can't silently diverge from the code. *(Contract-first by construction — see `docs/dev-guide/api-guide.md`.)*
- **Stripe Customer Portal** (E292) — `createPortalSession` + a Manage-billing button, plus billing **e2e** coverage.
- **Password-reset flow + invite emails** (E290) — migration **0007** adds `password_reset_tokens`; `inviteMember` now actually emails the invite.
- **HTTP security headers + CSP** (E289) — HSTS, `X-Content-Type-Options`, `X-Frame-Options`, Referrer-Policy, Permissions-Policy + a pragmatic Stripe-friendly CSP on all routes.
- **GitHub Actions CI** (E288) — typecheck · lint · test · build + a Postgres-service `db:test-migrate` job. *(Ships disabled — `workflow_dispatch`-only; uncomment the triggers to enable.)*
- **Baseline observability** (E293) — `instrumentation.ts` + env-gated Sentry (no-op when `SENTRY_DSN` is unset) + a structured `lib/logger.ts`; `lib/audit.ts` no longer swallows failures.

### Fork-ability (start your own SaaS)
- **One-knob rebrand** (E285) — set `NEXT_PUBLIC_APP_NAME` once (`lib/branding.ts` → logo / nav / footer / sidebar / `<title>`); root metadata template + `metadataBase`; demo-login gated strictly on the flag; `engines` pinned.
- **`@saas` install de-footgunned** (E284) — env-driven registry URL (`SAAS_REGISTRY_URL`), a guarded `install-landing` that won't delete your homepage, and drift warnings on the install skills.
- **Onboarding + deploy fixed** (E286, E287) — the fork guide is Next.js-native and the README routes to `docs/guides/`; the Zeabur deploy is single-service, the Dockerfile takes a `NEXT_PUBLIC_APP_URL` ARG, and GCP migrate/seed runs from the builder image with the correct seed path.

### Next.js-native Athena tooling + cleanup
- **Athena tooling reconceived** (E277, E282, E283) — `/athena:dba` → drizzle-kit, `/athena:audit` → Drizzle/Zod/UI drift; the **Stop-verifier** now enforces real Next.js invariants (8 rules, was 23 dead FastAPI/Vite ones); `/athena:domain` scaffolds a working domain by copying `items`.
- **Schema + API correctness** (E275, E276) — `lib/schema/` split by domain + migration 0006 (composite PKs / UNIQUEs / indexes); audit-logged `deleteUser`, transactional `acceptInvitation`, https-only webhooks, shared billing enums.
- **Dead-stack removed** (E278, E279, E280) — FastAPI/Vite worked examples + 33 dead scripts/config deleted; docs rewritten to Next.js; the Makefile is now Next.js-only.
