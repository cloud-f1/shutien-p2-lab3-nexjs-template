# Learning Path

## Progression

| # | Guide | Level | Est. Time | Description |
|---|-------|-------|-----------|-------------|
| 1 | [Quickstart](quickstart.md) | Beginner | 10 min | Clone, install, and run the dev environment with `make go` |
| 2 | [First Epic Walkthrough](first-epic-walkthrough.md) | Beginner | 30 min | Build a complete domain end-to-end using the Epic pipeline |
| 3 | [Working Without Claude Code](without-claude-code.md) | Beginner | 15 min | Full development workflow using only `make` commands and standard CLI tools |
| 4 | [AI Agent Team Guide](ai-agent-team-guide.md) | Intermediate | 15 min | Serial and parallel execution modes, command reference, observability |
| 5 | [Brainstorm-First Workflow](brainstorm-first.md) | Intermediate | 20 min | Use `/athena:plan brainstorm` to refine a feature idea into a structured epic before writing code |
| 6 | [CI Pipeline Explained](ci-explained.md) | Intermediate | 10 min | What CI checks run, common failures, and how to fix them |
| 7 | [OpenAPI Design Patterns](openapi-patterns.md) | Advanced | 20 min | 4 API patterns (CRUD, pagination, nested resources, file upload) with full four-layer mapping |
| 8 | [Building Domain Expert Agents](custom-agents.md) | Advanced | 20 min | Create custom AI agents for your specific business domain |

---

## How to Use This Path

**New to the project?** Start at #1 and work through sequentially. Guides #1-#3 give you everything needed to develop without AI assistance.

**Adding Claude Code?** Guides #4-#6 cover the agent team, brainstorm-first workflow, and CI integration. These unlock automated spec-driven development.

**Building advanced features?** Guides #7-#8 cover API design patterns and custom agent creation for domain-specific expertise.
